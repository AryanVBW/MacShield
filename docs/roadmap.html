Roadmap

Practical improvements, privacy first.

The roadmap prioritizes reliability, permission clarity, browser selector maintenance, accessibility, and safer defaults before expanding feature surface.

Now - Website, docs, and trust system

Landing page, documentation, support, legal, credits, roadmap, and status pages have been rebuilt for a production-ready public presence.

Next - Reliability pass

Improve overlay edge cases, protected app relock behavior, browser selector durability, and clearer in-app diagnostics.

Planned - Extension polish

Better onboarding for Website Lock, clearer permission copy, selector update workflow, and browser compatibility notes.

Later - Team readiness

Document managed deployment considerations, configuration export/import, and enterprise review checklists without adding telemetry.

Release principles

No new permission without documentation. No network behavior without clear disclosure. No analytics inside the app or extension.

Suggest a feature

Open an issue describing the user problem, privacy impact, and how it should fail safely.

Track updates

Use GitHub releases and the Sparkle appcast for native app release history.
