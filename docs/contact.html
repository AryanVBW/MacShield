Etiquette

Before you reach out

Following these guidelines keeps the project history useful for everyone and gets your issue resolved faster.

Please do

  • Search open and closed issues before filing a new one
  • Read the troubleshooting guide first
  • Include MacShield version, macOS version, and Mac model
  • Provide exact reproduction steps
  • Describe expected behavior vs. actual behavior
  • Attach redacted screenshots when relevant
  • Check you are on the latest release before reporting

Please do not

  • Post passwords, access tokens, or API keys in issues
  • Share unredacted private messages or screenshots
  • File duplicate issues for already-reported bugs
  • Post security vulnerabilities in public issues
  • Open issues asking for non-privacy features (e.g. cloud sync)
  • Cross-post the same issue across multiple channels
